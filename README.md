## 每回页的构成

封面书题 → 回目 → 连环画幅（画中题款 = 该幕原文，画下配场景与题款注）→ 原文 / 注释 / 白话译文 → 回评（臣光曰）→ 解说 → 上一回 / 下一回。

## 制作规范（定标）

1. 一致卡：每故事「人物卡 + 场景卡」常量逐幕原样注入，跨幕人物场景一致；敷彩画风下以服装颜色作人物区分锚点
2. 题款一律程序合成：底图无字（模型直题乱字不可控），方正清刻本悦宋竖排右起、去标点，合成前 fontTools 全量字表审计（GB 字集缺字会画成空白上墙）
3. 印章：卷一统一峄山碑篆体「资治通鉴」朱印（右列上下→左列上下）；题款字体与印章字体可分别指定
4. 校验：aicloud-kimi 原生分辨率裁检逐字复核 → 二意见 aicloud-qwen（繁简口音用原样字形指令）；篆体印文 OCR 不识属预期，以像素级比对证明
5. 底图与废稿归档各 drafts/（不入库），绝不删除

## 本地预览
